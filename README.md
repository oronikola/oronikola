# AdaptiveHub

We are the engineering team behind **AdaptiveHub**, a next-generation, AI-driven, multi-tenant learning ecosystem. Our mission is to build highly scalable, real-time, and deeply gamified educational software that bridges the gap between web platforms, cloud intelligence, and mobile experiences.

---

## 🌐 Our Product Ecosystem

We maintain an interconnected network of repositories that form the core AdaptiveHub infrastructure:

* **[`AdaptiveHub`](http://adaptivehub.app/landing)**: The primary LMS — adaptive, gamified, and AI-assisted. Designed for K-12 and higher education institutions with full web and mobile (Flutter) support.
